# デザインの規則

画面の見た目（書体・面・色）の使い分けを決める。昭和レトロな夜の屋台の世界観を保ちながら、
要素ごとに強弱をつけるのが目的で、どの要素も同じ処理（太い黒枠 + 生成りの板 + ずらした影）にしない。
デザインを変える Issue や PR は、この文書を根拠にする。規則を変えるときは、先にこの文書を直す。

色と書体の値は [src/app/globals.css](../src/app/globals.css) の `@theme` に、書体の読み込みは [src/app/layout.tsx](../src/app/layout.tsx) にある。

## 書体

2 書体と、ローマ字用の等幅に絞る。

| 書体 | クラス | 使う所 | 使わない所 |
|------|--------|--------|------------|
| Dela Gothic One（極太の看板書体） | `font-display` | 看板・のれん・提灯の文字、画面ごとの大見出し（「食券」「トッピング」「御会計」、ページの h1）、大きな数字（残り時間・平らげた杯数・お会計と差し引きの金額）、食券や「いただきます」など大きなボタンの名前、判子・のぼり | 小さなラベル、説明文、表の項目名と値、ボタンの補足、ページの h2 以下 |
| Zen Kaku Gothic New（角ゴシック）400 / 700 | `font-sans`（既定） | 本文とラベルのすべて。見出しやラベルは 700、説明文は 400 | — |
| Geist Mono（等幅） | `font-mono` | ローマ字（打つ文字、打ち間違えたキー） | ローマ字以外 |

- 丸ゴシック（Zen Maru Gothic）は使わない。
- 日本語の書体は重いので、先読み（preload）しない。
- 数字が並んで桁がそろってほしい所（表の値、値段）は `tabular-nums` を付ける。

### 字間と行間

| 対象 | 字間 | 行間 |
|------|------|------|
| 本文（舞台の外のページ） | 0（`letter-spacing` を足さない） | 1.7（`leading-body`） |
| 見出し（舞台の外のページ） | 0 | 1.3（`leading-heading`） |
| 看板・大見出し | 広げてよい（`tracking-widest` など） | 詰める（`leading-tight` / `leading-none`） |
| 舞台の中のラベル | 0 | 場所に合わせて `leading-tight` / `leading-snug` |

### 文字の大きさ

舞台の中は舞台の幅（`cqw`）で大きさを決める。舞台が幅 960px のとき 1cqw = 9.6px なので、文字は 1.25cqw（12px）以上にする。
舞台が縮んでも読ませたい札は `max(11px, …)` のように下限を付ける。

## 面（ボタン・板・紙）

押せるものと押せない情報の表示を、見た目で分ける。

| 種類 | 見た目 | 使う所 | 書き方 |
|------|--------|--------|--------|
| 押せるもの | 太い黒枠（`border-[0.35cqw] border-yatai-sumi`）+ 下にずらした影。押すと沈む（`active:translate-y-*` で影を消す） | 食券のボタン、トッピングの札、いただきます、もう一杯、X で共有、効果音の札、環境音・BGM の札 | 各ボタンのクラス |
| 木の板 | 枠線なし。木目の色（`wood-dark`）の面に生成りの文字。上端だけ少し明るい | 押せない情報のうち、屋台に掛けた札（連続杯数、閉店間際の知らせ、トッピング、タッチ端末への案内） | `stage-wood-board` |
| 紙 | 枠線なし。生成りの面に墨の文字。ごく弱い影 | 押せない情報のうち、読ませる文章や伝票（注文の札、遊び方の貼り紙、トッピングのお品書き、日本語入力の案内、お会計の伝票） | `stage-paper` |
| 吹き出し | 紙と同じ（枠線なし・ごく弱い影）で、角を大きく丸める | 店主のひとこと、替え玉の知らせ | 紙の色と影を直接書く |
| 看板・絵 | 屋台の絵と同じ黒い輪郭線 | 店の看板（`StageSign`）、SVG の絵、絵に溶け込ませた情報（柱の時計の残り時間、積んだ丼と杯数、丼の下ののびるまでのゲージ、麺玉の替え玉ゲージ） | — |

- 「太い黒枠 + ずらした影」は押せるものだけに使う。押せない情報に付けない。
- `stage-wood-board` / `stage-paper` は大きさを `cqw` で持つので、舞台の中だけで使う。
  舞台の外のページで同じ面を使うときは、`rounded-md` と px の値で書く（例: 紹介のコースの札は木の板）。
- `stage-wood-board` / `stage-paper` は `box-shadow` を使うので、`ring-*` と組み合わせない。縁取るときは `outline-*` を使う。

### カーソル

- 押せる要素（ボタン、リンク、トッピングの券などクリックで操作できるもの）にマウスを載せると、カーソルを指の形（`pointer`）にする。
- 押せない状態のボタン（`disabled`）と、押せない情報の表示（残り時間・伝票・貼り紙など）は指の形にしない。
- Tailwind CSS 4 ではボタンのカーソルが矢印に戻るので、`src/app/globals.css` の `@layer base` でサイト全体の規則として指定している。
  ボタンを足すときに `cursor-pointer` を個別に書かない。リンク（`<a href>`）はブラウザの既定で指の形になる。

### 角の丸み

| 対象 | 丸み |
|------|------|
| 押せるもの・木の板・札 | 0.6cqw（舞台の外は `rounded-md`） |
| 紙・伝票 | 0.2cqw |
| 吹き出しだけ | 1.2cqw |

## 色

| 色 | トークン | 使う所 | 使わない所 |
|----|---------|--------|------------|
| 提灯の赤 | `lantern` | 看板・提灯・のれん、各画面でいちばん押してほしいボタン 1 つ（トッピングの「いただきます」、結果の「もう一杯」） | 見出し・ラベルの文字、押せない札の面、強調 |
| 朱 | `lantern-dark` | 紙の上の強調（打ったローマ字、お得の金額、判子、トッピングの値段の倍率、注意の文）。琥珀色は紙の上では読めないので、紙の上では朱で強調する | 夜空や木の板の上の文字 |
| 琥珀色 | `amber` | 夜空や木の板の上で強調したい数字や状態（連続ボーナスの倍率、のびかけ、閉店間際、連続が途切れた、店主のおすすめ、自己ベスト更新）、フォーカスの縁、リンクに載せたとき | 見出しの文字色、ラベル、リンクの普段の色 |
| 藍 | `ai` | 損の金額 | — |
| 生成り | `kinari` | 夜空・木の板の上の文字、紙の面 | — |
| 墨 | `sumi` | 紙・琥珀色の面の上の文字、押せるものの枠と影 | — |

- 本文の文字は生成りか墨にする。補足のラベルは生成りを薄くした `text-yatai-kinari/75` まで。
- 文字色と背景色は WCAG AA の 4.5:1 以上を取る。提灯の赤の上の生成りは 4.5:1 に届かないので、大きな文字（看板・大きなボタンの名前）にだけ使う。
  組み合わせごとのコントラスト比は [tests/app/globals-css-contrast.test.ts](../tests/app/globals-css-contrast.test.ts) で確かめている。

| 文字 | 背景 | 基準 |
|------|------|------|
| 生成り | 夜空（`night` / `night-deep`）・木の板（`wood-dark`） | 4.5:1 |
| 琥珀色 | 夜空（`night-deep`）・木の板（`wood-dark`） | 4.5:1 |
| 墨・朱・藍 | 紙（`kinari`） | 4.5:1 |
| 墨 | 琥珀色 | 4.5:1 |
| 生成り | 提灯の赤（`lantern`） | 大きな文字だけ 3:1 |

## 動き

屋台の背景（`YataiScene` / `YataiSky` / `YataiStall`）に、夜の屋台の生活感を出す小さな動きを付ける。
ゲームの邪魔にならないよう、どれも控えめにする。動きの値は [src/app/globals.css](../src/app/globals.css) の `@theme` の `--animate-*` と `@keyframes` にある。

- 動きは位置・大きさ・回転・透明度の変化（`transform` / `opacity`）だけで作り、CSS のアニメーションで動かす。
  キー入力のたびに JavaScript で動かさない。
- 背景の動きは SVG の絵の中だけで起こす。注文の文・よみ・ローマ字などの文字は絵より手前に重ねているので、動きが文字を隠すことはない。
  猫など画面を横切る絵は、丼や注文の札より下（舞台の高さの 39.5% より下）を通さない。
- 動きを抑える設定（`prefers-reduced-motion: reduce`）では、背景の動きを止める。`motion-safe:` で付け、止めたときの姿は普段の姿にする
  （星は灯ったまま、のれんは垂れたまま、店主は目を開けて腕を下ろしたまま、猫は出さない）。背景の動きは飾りで、止めても伝わる情報は変わらない。
- 足す絵は自作の SVG で描き、屋台の絵と同じ黒い輪郭線と配色（`yatai-*`）にする。

| 何が | いつ | どれくらいの長さで | どの画面 |
|------|------|--------------------|----------|
| 夜空の星（`star-twinkle`） | ずっと。星ごとに長さと始まりをずらし、一斉に点滅させない（`src/client/lib/yatai-ambient.ts`） | 1 回の瞬きが 2.4〜5.2 秒。透明度を 1 → 0.3 → 1 | すべての屋台の画面 |
| 提灯（`lantern-sway`） | ずっと | 片道 3.6 秒で左右に 3 度ずつ | すべての屋台の画面 |
| のれん（`noren-flutter`） | 9 秒ごとに 1 度、風を受けたように揺れて止まる。布ごとに 0.15 秒ずつ遅らせる。提灯（往復 7.2 秒）と周期をずらす | 揺れている間は約 3 秒。上端を支点に最大 7 度傾ける | すべての屋台の画面 |
| 店主のまばたき（`shopkeeper-blink`） | 4.6 秒ごと。笑顔（目を細めた顔）ではしない | 約 0.3 秒 | すべての屋台の画面 |
| 店主の湯切り（`shopkeeper-yuchiri`） | 11 秒ごとに 1 度、腕を上げてテボを小刻みに振り、また下ろす | 上げ下ろしを含めて約 2 秒 | すべての屋台の画面 |
| 屋根の上を横切る猫（`stray-cat`） | 画面を出してから 13〜22 秒に右から左へ、40〜49 秒に左から右へ、1 度ずつ（1 プレイに 2 回）。それ以降は出さない | 1 回の横切りが約 7 秒 | プレイの画面だけ（画面ごとに数え直さないよう、トッピング・結果・券売機の画面には出さない） |
| 丼の湯気（`steam-waver`） | ずっと | 片道 1.8 秒で左右にゆらぐ | プレイの画面 |
