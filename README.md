# ramen-typing-game

夜のラーメン屋台で、出てくる注文をローマ字で打って平らげていくタイピングゲーム。
券売機で食券を買うと、食券の時間内は食べ放題。麺がのびる前にどんどん食べて、お会計で食券代の元を取ろう。

## 遊び方

1. **食券を選ぶ。** 屋台の脇の券売機で、腕前に合わせてコースの食券を買う。

   | 食券 | 食券代 | 食べ放題の時間 | 注文の長さ |
   |------|--------|----------------|------------|
   | 並 | 3,000 円 | 60 秒 | よみ 2〜7 文字 |
   | 大盛り | 5,000 円 | 90 秒 | よみ 5〜10 文字 |
   | 特盛り | 10,000 円 | 120 秒 | よみ 9 文字以上 |

2. **注文を打つ。** 丼が出てきたら、注文のよみをローマ字で打つ。打ち切ると平らげたことになり、丼の値段がお会計に足される。
   「し」を `shi` でも `si` でも打てるように、よくあるつづりはどれでも受け付ける。
3. **麺がのびる前に食べる。** 丼は出てから時間がたつと麺がのびていく。
   - 出てすぐ平らげると、できたての上乗せで定価より高くなる
   - のびかけになると、定価より安くなっていく
   - のびきると丼は下げられ、お会計には入らない
4. **替え玉で時間を延ばす。** ミスなしで 30 キー続けて打つと替え玉になり、食べ放題の時間が 2 秒延びる。
5. **ミスなしで続けて平らげる。** ミスせず、丼を下げられずに続けて平らげると、連続ボーナスで丼の値段に倍率がかかる（3 杯目から ×1.1、5 杯目から ×1.2、10 杯目から ×1.5）。
6. **店主のおすすめを狙う。** ときどき出る「店主のおすすめ」の特別な丼は、値段が 2 倍になる。

時間が来ると閉店。結果画面で、お会計と食券代の差し引き（お得か損か）、称号、正確率、打ち間違いの多いキーなどが分かる。
コースごとの自己ベストが残り、結果は X で共有できる。

券売機の画面の「スタンプカード」から、遊んで集めた判子（実績）を見られる。

## 遊ぶのに必要なもの

- 物理キーボード（スマホやタブレットのタッチ操作では文字を打てない）
- 日本語入力（IME）をオフにして、半角英数で打つこと（オンのまま打つと、切り替えるよう案内が出る）

## 開発者向け

タイピングゲームを、ループエンジニアリング（AI エージェントが Issue を自律実装し、CI と CodeRabbit が通れば自動マージする開発手法）で開発している。

### 必要なもの

- Node.js 24 以上
- pnpm 10
- [GitHub CLI](https://cli.github.com/)（`gh auth login` 済み）
- [Claude Code](https://claude.com/claude-code)（ループを回すマシンのみ）

### はじめかた

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm verify     # lint / typecheck / test / depcruise / knip
pnpm build      # 本番ビルド
```

### 環境変数

| 名前 | 用途 | 未設定のとき |
|------|------|-------------|
| `NEXT_PUBLIC_CONTACT_FORM_URL` | お問い合わせページ（`/contact`）から新しいタブで開く Google フォームの URL | リンクを出さずに「準備中」と出す |

`NEXT_PUBLIC_` の変数は**ビルド時に値が埋め込まれる**。ホスティング（AWS Amplify など）のコンソールで設定し、変えたら再ビルドする。
ローカルでは `.env.local` に書く。

### ループを回す

GitHub 側の設定（ラベル、CodeRabbit、ブランチ保護、auto-merge）が済んでいないと、ループは安全に回せない。
先に [docs/loop-engineering.md](docs/loop-engineering.md) の「GitHub 側のセットアップ」を済ませること。

```bash
pnpm --silent loop:decide   # 次に何をするかを確かめる（読み取り専用）
pnpm loop:once              # 1 tick だけ実行
pnpm loop 10                # SUCCESS が 10 回になるまで回す
```

タスクは Claude Code で `/loop-issue <やりたいこと>` を実行して起票する。
